# Resultados e Impacto

## 1. Visão geral

O Quiz foi desenvolvido para uma iniciativa corporativa de Diversidade e Inclusão realizada em 2026.

A aplicação foi utilizada durante um evento específico, alcançando mais de 1.000 participantes.

O projeto teve como principal objetivo digitalizar a experiência do questionário e simplificar o gerenciamento dos resultados.

## 2. Alcance

- **Período:** evento corporativo realizado em 2026.
- **Participação:** mais de 1.000 participantes.
- **Acessos registrados:** 4.174 acessos ao site.
- **Plataforma:** aplicação web hospedada no Firebase Hosting.

Os números de participantes e acessos representam métricas distintas e não devem ser interpretados como equivalentes.

## 3. Impacto operacional

Um dos principais benefícios da aplicação foi a automatização da administração dos resultados.

O painel administrativo centralizou funcionalidades que facilitam o acompanhamento das participações, incluindo:

- Consulta dos resultados registrados.
- Organização automática do ranking.
- Visualização de indicadores gerais.
- Exportação de relatórios em formato XLSX.
- Consolidação dos dados em diferentes planilhas.

Essa estrutura reduziu a necessidade de organizar manualmente os resultados e tornou as informações mais acessíveis aos responsáveis pela administração do evento.

## 4. Desenvolvimento

O projeto foi desenvolvido com participação individual na implementação técnica e apoio de outras pessoas envolvidas no contexto da iniciativa.

A solução integrou desenvolvimento front-end, persistência de dados em nuvem, autenticação administrativa, acessibilidade e geração de relatórios.

## 5. Aprendizados técnicos

O desenvolvimento proporcionou experiência prática em:

- Construção de aplicações web com HTML, CSS e JavaScript.
- Integração com serviços Firebase.
- Modelagem e persistência de dados NoSQL.
- Implementação de autenticação e controle de acesso.
- Manipulação de dados e construção de rankings.
- Geração de relatórios XLSX.
- Visualização de indicadores com gráficos.
- Desenvolvimento de interfaces responsivas e recursos de acessibilidade.

## 6. Considerações finais

O Quiz demonstra a aplicação de conhecimentos de desenvolvimento web na construção de uma solução voltada a uma necessidade organizacional concreta.

Além da interface interativa, o projeto contemplou persistência de dados, gerenciamento administrativo e geração de relatórios, proporcionando uma experiência prática de desenvolvimento de uma aplicação integrada a serviços em nuvem.
