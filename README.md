## 01. Overview

VIA is a web application developed for a corporate Diversity & Inclusion initiative.

The platform provides an interactive quiz experience for participants and an administrative environment for managing participation data, monitoring results and generating reports.

The project combines front-end development, cloud-based data persistence, authentication and data visualization in a single web solution.

## 02. Project Impact

| Metric | Result |
|:---|---:|
| Participants | **4,000+** |
| Website accesses | **4,174** |
| Project year | **2026** |

*Participant count and website accesses represent different metrics.*

## 03. Key Features

- Interactive quiz with randomized questions.
- Portuguese and Spanish language support.
- Responsive user interface.
- Accessibility features, including high contrast and text-to-speech.
- VLibras integration.
- Cloud-based result storage.
- Restricted administrative dashboard.
- Participant ranking and statistical indicators.
- Excel report generation with multiple worksheets.

## 05. Architecture

The application is organized around two main interfaces:

**Participant Interface**
- Registration and participant information.
- Dynamic quiz presentation.
- Score calculation.
- Language selection.
- Result submission to Firestore.

**Administrative Interface**
- User authentication.
- Administrative permission verification through Firebase custom claims.
- Participant data retrieval.
- Ranking and statistical indicators.
- XLSX report generation.

The solution uses Firebase as a Backend as a Service (BaaS), reducing the need to maintain a dedicated application server.

## 06. Development Challenges

Some of the main technical challenges involved:

- Building the application without front-end frameworks.
- Implementing dynamic question selection.
- Managing bilingual content.
- Integrating Firebase services.
- Structuring administrative access control.
- Processing and organizing participant data.
- Generating spreadsheets with embedded visualizations.
- Implementing accessibility features.
